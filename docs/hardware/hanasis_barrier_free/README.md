## 2. ⌨️ `HID HKP-200D` (방향 키패드) 공장 기본 키코드 (`Utility Manual p.3`)

별도 API/SDK 없이 **표준 USB HID 키보드 이벤트(`keydown`)**로 수신됩니다. 필요 시 전용 유틸리티로 원하는 키코드로 변경 가능하며, 변경하지 않으면 유틸리티 미설치 상태에서도 아래 공장 기본 키코드로 즉시 동작합니다.

| 물리 버튼 / 이벤트 | 공장 기본 키코드 | SW 권장 매핑 & 주의사항 |
| :--- | :---: | :--- |
| **좌측 상단 `[+]`** | **`F11`** | 음량 크게 (⚠️ Electron/브라우저 전체화면 토글과 충돌하므로 `e.preventDefault()` 및 `electron/main.cjs` 가로채기 필수) |
| **좌측 중단 `[-]`** | **`F12`** | 음량 작게 (⚠️ DevTools 단축키와 충돌하므로 프로덕션 `e.preventDefault()` 필수) |
| **상/하/좌/우 방향키** | **`ArrowUp` / `ArrowDown` / `ArrowLeft` / `ArrowRight`** | 2차원 포커스 이동 및 항목 음성 낭독 |
| **중앙 원형 확인 버튼** | **`Enter`** | 현재 포커스 항목 실행/선택 |
| **우측 상단 기능 버튼** | **`F1`** | 음성 다시 듣기 / 홈 / 취소 등 보조 기능 |
| **🎧 이어폰 잭 삽입 (`Audio Jack IN`)** | **`F15`** | **배리어프리 음성안내(TTS) 모드 자동 활성화** 트리거 |
| **🎧 이어폰 잭 제거 (`Audio Jack OUT`)** | **`F16`** | **음성안내(TTS) 모드 자동 해제** 트리거 |

- **내장 부저(`Enable Buzzer`)**: 키패드 하드웨어 자체에서 키 입력 시 "삑" 피드백 음 지원.
- **USB 바코드 스캐너 분리**: `useHardwareScanner.ts`는 연속 영숫자+Enter 버스트만 스캔으로 취급하고, `Arrow*` / `F1` / `F11` / `F12` / `F15` / `F16` 및 포커스 모드 단독 `Enter`는 배리어프리 포커스 엔진이 우선 소비하도록 분리 필요.

## 3. 📐 저자세(낮은 화면) 모드 실측 기준 (`K-270F` 도면 기반)

- **전체 높이**: `1,600mm` (스탠드 `710mm` + 본체 `890mm`), 27인치 활성 화면 높이 `~598mm` (하단 시작점 `~980mm`).
- **휠체어 조작 상한(`1,220mm`) 대응 범위**: 화면 최하단 약 `240mm` 구간 = 전체 세로 해상도(`1920px`) 중 **하단 약 40% (`~770px`, `Y: 1150px ~ 1920px`)**.
